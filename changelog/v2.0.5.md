# 2.0.5 — In Development

Minecraft 1.21.1 | Fabric, NeoForge

## API

| Tag | Change |
|---:|---|
| ![bugfix] | <details><summary>Fabric dedicated server crashed at mod init with `AbstractMethodError` on `NetworkManagerImpl$1.registerS2C`</summary><br>**Root cause:** Architectury 13.0.8's Fabric adaptor annotates `registerS2C(...)` with `@Environment(EnvType.CLIENT)`. Fabric Loader strips that method on the dedicated server, so any `NetworkManager.registerReceiver(Side.S2C, ...)` from common init dispatched into the missing method and threw. NeoForge and singleplayer were unaffected.<br><br>**Fix:** `ModUtilitiesMod.registerSharedPackets()` and all three public `NetworkPacketManager.registerS2C(...)` overloads now branch on `Platform.getEnvironment()` — the client installs the full receiver (which also registers the payload TYPE), the dedicated server registers only the payload TYPE via `NetworkManager.registerS2CPayloadType(...)`. Mutually exclusive to avoid double-registering the type on the client.<br><br>Public API signatures unchanged — downstream mods (BankSystem, StockMarket) need no code changes.</details> |
