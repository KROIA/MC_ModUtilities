# 2.1.2 — In Development

Minecraft 1.21.1 | Fabric, NeoForge

## API

|         Tag | Change |
|------------:|--------|
| ![feature] | Unit test runs are now written to disk. `TestRunner` produces one report per mod at `logs/UnitTests/<modId>.log`, containing the run header, per-category blocks, every `PASS`/`FAIL`/`ERR` line with its expected/actual detail, and a final summary. The previous file is deleted at the start of each run, so a report always reflects exactly one run. |
| ![feature] | Test reports also capture ordinary logging. While a run is in progress a log4j appender is attached to the root logger, so everything any mod logs between tests is interleaved into the report in chronological order, formatted as `[HH:mm:ss] [thread/LEVEL] [logger]: message` including stack traces. The appender is detached when the run ends. |

## Internal

|         Tag | Change |
|------------:|--------|
| ![hardening] | `TestRunner` now catches `Throwable` (not just `Exception`) around setup, each test, and teardown, and runs teardown from a `finally` block. A `NoSuchMethodError` or `AssertionError` from a single test can no longer escape into the server tick loop, and world state acquired by a partially completed `setup()` still gets released. Full stack traces go to the server log; chat gets a short `Type: message` form that no longer renders as `null` for message-less throwables. |
