# 2.1.0 — In Development

Minecraft 1.21.1 | Fabric, NeoForge

## UI/UX

|         Tag | Change |
|------------:|--------|
| ![feature]     | New `MultiLineTextBox` GUI element with word wrap, multi-line editing, and vertical scrolling. |
| ![feature]     | `Label` now auto-scrolls overflowing text horizontally; toggle via `setAutoScrollEnabled()` / `setManualScrollOffsetX()`. |
| ![improvement] | `TextBox` scrolls its view to keep the cursor visible and clips cursor/selection to the field bounds. |
| ![improvement] | `TextBox` cursor redrawn as a thin text-height caret with a brighter default color. |
| ![bugfix]      | `DropDownMenu` no longer swallowed clicks — the trigger now reports handled clicks correctly. |

## Internal

|         Tag | Change |
|------------:|--------|
| ![improvement] | Added arrow, page, home, and end key codes to `InputConstants`. |
| ![improvement] | Sandbox `ExampleFormScreen` extended with a multi-line description field and an overflowing label demo. |
